# baidu.com

GitHub Pages serves this repository from the root of the `main` branch.

- Main page: `index.html`
- Additional page: `index1.html`

Site URL: https://bilbilil.github.io/baidu.com/

## 管理页面内容

1. 登录 [Pages CMS](https://app.pagescms.org/) 并使用有此仓库写入权限的 GitHub 账号。
2. 首次使用时，将 Pages CMS GitHub App 安装到 `bilbilil` 账号，并允许访问 `baidu.com` 仓库。
3. 打开仓库后编辑“主站内容”或“备用页内容”；图片上传到 `media/`。
4. 保存后 Pages CMS 会提交修改到 `main`，GitHub Pages 随后自动重新发布。
